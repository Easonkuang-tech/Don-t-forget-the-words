RepLoop Privacy Policy

Last updated: 2026-10-05

Data we process

RepLoop stores the email address used to sign in, vocabulary projects, decks, cards, review history, and learning settings. This data is stored in Supabase and associated with the signed-in user.

Browser extension

The Edge extension reads text only after the user selects it or chooses the RepLoop context menu action. Selected text is sent to the RepLoop service for dictionary lookup or translation. The extension stores its login session and temporary selected text in browser extension storage.

Permissions

Host permissions are limited to the RepLoop service and its Supabase project. The extension does not sell personal data or use it for advertising.

Data deletion

Users can delete cards and projects in RepLoop. Account and cloud data deletion requests can be sent to the support address listed on the Edge Add-ons store page.
